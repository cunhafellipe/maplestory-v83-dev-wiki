# UI.wz 結構

UI.wz 是 MapleStory v83 客戶端最關鍵的資料檔。

## 主要內容

```
UI.wz
├── UI/UIWindow.img/    ← 主要視窗(道具/裝備/技能/任務)
├── UI/Login.img/       ← 登入視窗
├── UI/StatusBar.img/   ← 狀態列
├── UI/ITC.img/         ← NPC 對話視窗
└── ...
```
